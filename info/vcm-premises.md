# Virtual Cell Models

## Introduccion al concepto
- Si se llegan a generar un Virtual Cell Model, se podrian forma clusteres de celulas, escalando estos modelos computacionalmente y poder simular tejidos, tumores, u organoides.
- Podriamos inferir la prognosis, diagnostico del tejido si podemos hacer un Digital Twin
- Saber de antemano que Clinical Trial o Ensayo Clinico (ver Clinicaltrials.gov) puede funcionar mejor para el tejido o tumor, examinando el perfil del paciente con un Virtual Cell Model. 

## Problema a resolver
- Tengo la premisa de que para desarrollar Virtual Cell Models se necesita una cantidad enorme de datos que no tenemos.
- El Virtual Cell Model puede generar simulaciones con perturbation data. De aqui se puede generar datos sinteticos de estas simulaciones. ¿Pero estos datos al ser sinteticos tienen buena calidad para que sirva para entrenar mas modelos?
- Para escalar modelos de inteligencia artificial, incluidos estos Virtual Cell Models, los cuellos de botella son la cantidad de datos y la cantidad de computacion. 
- ¿Quien actualmente esta diseñando estos modelos? ¿Explicame como funcionan?
